# 🎁 TikTok Auction Tool

Tool đấu giá TikTok Live với tính năng Snap Time (hiệp phụ khi hòa điểm).

## ✨ Tính năng

- 📡 Đọc quà tặng TikTok Live realtime
- 🏆 Bảng xếp hạng top 10 cập nhật trực tiếp
- ⚡ **Snap Time**: tự động kích hoạt khi có nhiều người bằng điểm top 1
- 🎨 Overlay đẹp cho TikTok Studio / OBS
- 🖥️ GUI desktop (không cần mở browser)
- 📦 Build ra file .exe chạy độc lập
